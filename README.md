# Property Lane

Property Lane is a static real estate homepage. Visitors can browse featured homes, filter by buy, rent, or sell, and find the office contact details in the footer.

## Pages

The site is a single page, `index.html`.

| Section | What it shows |
| --- | --- |
| Navigation | Search, Home, Template, Contact, Docs, Sign in, and Sign up |
| Hero | “Let us guide you home,” with a cover image |
| Search | Buy, Rent, and Sell tabs with location, property type, and price |
| Featured listings | A carousel of homes, including location and price |
| Cities | San Francisco, Los Angeles, Santa Monica, San Diego, and Fresno |
| Why us | Investment, booking, purchase, and evening highlights |
| Team | Four team members |
| Footer | Brand, contact details, rental links, page links, and an offers form |

## How to view it

Open `index.html` in a browser. No build step or local server is required. Styles live in `style.css`. Bootstrap, Font Awesome, Remix Icon, jQuery, and Owl Carousel load from CDNs, so the page needs an internet connection for layout, icons, and the listing carousel.

## Stack

- HTML
- CSS
- Bootstrap 5
- jQuery and Owl Carousel for the featured listings
